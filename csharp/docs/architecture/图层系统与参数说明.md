# 图层系统与参数规范说明

## 1. 组合图层架构设计

重构后的多边形地图系统采用了**底图单选互斥（BaseTheme）与叠加图层多选（Overlays）**的正交组合架构，彻底废除旧系统中单一枚举图层相互割裂的局限。

```
┌────────────────────────────────────────────────────────┐
│                    图层渲染栈 (LayerStack)              │
├────────────────────────────────────────────────────────┤
│ 8. 聚落与注记层 (Cities & Labels)   [矢量 Overlay]     │
│ 7. 贸易走廊网络 (Trade Routes)      [矢量 Overlay]     │
│ 6. 政体国界领地 (Polity Borders)    [矢量 Overlay]     │
│ 5. 河流水系网络 (Rivers)            [矢量 Overlay]     │
│ 4. 海岸轮廓外边 (Coastlines)        [矢量 Overlay]     │
│ 3. 风向与洋流   (Wind Arrows)       [矢量 Overlay]     │
│ 2. 地质板块边界 (Plate Borders)     [矢量 Overlay]     │
│ 1. 多边形地块线 (Cell Borders)      [矢量 Overlay]     │
├────────────────────────────────────────────────────────┤
│ 0. 基础底图主题 (13 选 1 互斥底图)   [基础 BaseTheme]   │
└────────────────────────────────────────────────────────┘
```

## 2. 13 种基础底图主题（BaseTheme）

每个地块基于 `WorldSnapshot` 中的属性被赋予唯一的特征颜色：

| 标识符 (ID) | 中文名称 | 所属分类 | 依赖核心数据字段 | 表现与用途 |
|---|---|---|---|---|
| `terrain_overview` | 地形总览 (卫星) | 地理 | Height, Temperature, Moisture, Biome, River | 拟真卫星遥感图，融汇植被覆盖、高山雪顶、沙地与冰川极地 |
| `inkwash_landscape` | 山水舆图 (水墨青绿) | 地理 | Height, Temperature, Moisture, Landform, River, Biome, Influence | 中国古代手绘山水舆图风格：宣纸地子承托青绿设色，海拔走"青绿丘陵 → 浅绛山麓 → 靛墨山脊 → 浓墨高山"晕染阶，湿度定冷暖，水系敷碧蓝、大漠铺淡金、火山点朱砂、京畿染暖金；留白只落在又高又寒的山巅，并叠加确定性宣纸纤维颗粒。**该底图激活时叠加层同步换笔法**：河流改敷碧蓝、聚落改墨绘城邑符号（都城重郭楼阁 / 城镇单郭方城 / 村落人字村舍）、地名改纸面晕底墨书，并为全图最尊的都城钤一方朱砂印 |
| `elevation` | 高程分层 | 地理 | Height, SeaLevel | 从深海海沟蓝、大陆架浅海到低平原绿、高原棕褐与极峰雪白的标准分层色谱 |
| `landform` | 地貌构造 | 地理 | Landform | 参考真实地球地貌学体系的 25 类宏观与微观构造，分为四大地质营力范畴：**海洋地貌**（洋盆、深海平原、海沟、海岸、海岛、陆架浅海、大洋中脊）、**构造地貌**（平原、盆地、干盆地、高原、丘陵、山脉、极峰、裂谷、火山）、**流水地貌**（泛滥平原、三角洲、峡谷、岩溶喀斯特、湿地沼泽）、**气候风成/冰川地貌**（风成沙丘、荒漠雅丹、冰川雪原、冰川峡湾） |
| `biomes` | 生物群系 | 地理 | Biome | 惠特克生态群系（雨林、季节林、稀树草原、温带草原、冻原、寒温带针叶林等 21 类） |
| `temperature` | 地表气温 | 气候 | Temperature | 从 -45℃ 极寒靛蓝、适温嫩绿到 55℃ 酷热橙红的平滑连续梯度 |
| `moisture` | 降水湿度 | 气候 | Moisture | 浅蓝灰（干燥）至深海青（极湿）的水汽湿度梯度 |
| `plates` | 地壳板块 | 地质 | PlateId, PlateBoundary | 各大陆与大洋板块的伪随机色块填充，直观显示板块漂移格局 |
| `rock_types` | 岩石地质 | 地质 | Rock, Height | 沉积岩（暖沙色）、火成岩（暗红岩浆色）、变质岩（深冷灰色） |
| `ores` | 矿产分布 | 地质 | Ore, Height, MagicDensity | 矿化只落在出露的陆壳上，海平面以下一律无矿；门槛取陆地矿化异常度的 88 分位，约 12% 陆地成矿，品位按矿体内部名次分档。矿种分三阶：**凡铁**石炭/紫铜/赤铁/白银/黄金 → **灵材**灵石/玉髓/玄铁/秘银 → **神料**精金/星辰砂/太乙神铁。魔法丰度决定灵化门槛：零魔世界只有凡铁，丰度拉满则过半矿点升华，且神料只在高魔世界凝得出来。**该底图激活时自动绘出大陆轮廓**（玩家未勾选海岸轮廓时由底图代绘），否则稀疏矿点无法定位归属哪块陆地 |
| `ecology` | 生态状态 | 人文 | EcologyHealth, Height | 地表生态系统繁荣度与文明承载健康指数（赤红衰败至翠绿蓬勃） |
| `civilization` | 文明疆域 | 人文 | Influence, PolityId, BorderMask | 各大政体实际管辖势力范围色块与核心腹地高亮 |
| `cell_grid` | 地块网格调试 | 诊断 | 无（纯几何） | 中性浅灰底色展示地块单元划分，用于诊断 Voronoi 几何均匀度与接缝质量 |

## 3. 8 种矢量叠加图层（Overlays）

所有叠加图层可独立开启/关闭，支持 0%~100% 透明度调节、0.5~5.0 像素线宽/尺寸调节，并可自由上下调整绘制优先级：

1. **河流水系 (`rivers`)**：
   - 依据下游拓扑（Downslope）与局部汇流积分（Flux）计算的矢量主干支流。
   - 流量越大，河流矢量线越粗，自然汇入湖泊或海洋。
2. **海岸轮廓 (`coastlines`)**：
   - 提取陆地多边形与海洋多边形相邻的公共分界边线。
   - 描绘清晰的陆海界限，压住海岸细节。
3. **政体国界 (`polity_borders`)**：
   - 提取不同政体控制地块之间的分界边线。
   - 以明亮金黄色高亮国家主权边界。
4. **聚落城镇 (`cities`)**：
   - 绘制村落（Hamlet）、城镇（Town）、城邦主城（CityState）三级矢量标记与地名标签。
5. **贸易走廊 (`trade_routes`)**：
   - 连接各大城邦与繁华城镇的最佳陆路与海运交通走廊。
6. **地块线框 (`cell_borders`)**：
   - 绘制所有多边形地块的边界轮廓，直观透视多边形格网细节。
7. **风向洋流 (`wind_arrows`)**：
   - 在地块质心处绘制气流方向与风速矢量箭头。
8. **板块边界 (`plate_borders`)**：
   - 根据边界运动类型分色标记：聚合消亡边界（红色）、离散扩张脊（青色）、转换断层（黄色）。

## 4. 6 种内置图层预设（Presets）

系统提供了一键切换的常见业务预设，也可以切换到“自定义”自由配置：

| 预设名称 | 基础底图 | 默认启用的叠加图层 | 适用场景 |
|---|---|---|---|
| **自然地理** (默认) | 地形总览 (`terrain_overview`) | 河流水系 + 聚落城镇 | 经典全景地图，探索地理世界 |
| **政治文明** | 文明疆域 (`civilization`) | 河流水系 + 聚落城镇 + 政体国界 | 国家领土格局、势力划分与地缘博弈 |
| **贸易网络** | 地形总览 (`terrain_overview`) | 河流水系 + 聚落城镇 + 贸易走廊 + 政体国界 | 考察商业枢纽、商道畅通率与走廊覆盖 |
| **气候分析** | 地表气温 (`temperature`) | 河流水系 + 风向洋流 | 分析盛行风系、降水拦截与冷暖环流 |
| **地质资源** | 地壳板块 (`plates`) | 板块边界 + 地块线框 | 构造地质分析、造山带与矿脉推演 |
| **地块调试** | 地块网格 (`cell_grid`) | 地块线框 + 河流水系 + 聚落城镇 | 开发者诊断多边形网格拓扑、缝隙与密度分布 |

## 5. 地图规模与分辨率解耦规范

### 5.1 地块规模（TargetCellCount）
- **默认档位**：**10,000 块**（兼顾丰富细节与亚秒级即时模拟）。
- **预设档位**：
  - `2,048 块 (极速)`：低端设备或快速探索。
  - `5,000 块 (流畅)`：平衡快速响应。
  - `10,000 块 (标准 · 默认)`：推荐全景体验。
  - `20,000 块 (精细)`：超高地块密度。
  - `32,768 块 (极致)`：地貌微结构极致拟真。
  - `自定义`：支持 1,000 ~ 65,536 范围内精确整数输入。
- **透明展示原则**：界面严格同时显示“目标数量”与“实际生成数量”（如 `目标 10,000 · 实际 10,011`），由于 Voronoi 泊松分布及经纬圆柱拓扑的整除取整，实际地块数通常与目标值存在轻微偏差（通常 $< 1\%$），系统绝不以假充真。

### 5.2 渲染与导出分辨率（Resolution）
- **默认分辨率**：**2048×1024（2K）**，沿用 2:1 全图经典宽高比。
- **可选档位**：
  - `1K (1024×512)`：节省显存与微型预览。
  - `2K (2048×1024 · 推荐默认)`：清晰平衡。
  - `4K (4096×2048 · 超清)`：专业海报级高质量 PNG 导出。
- **正交解耦**：改变分辨率只影响底图采样着色网格与 PNG 画质，**绝对不改变任何地块形状、高度、水文、聚落位置或缓存签名**。
