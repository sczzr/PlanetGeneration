# 多边形地图架构设计规范

## 1. 核心设计原则

本系统将世界地图从“先生成栅格像素、再附会多边形表现”的旧模式，彻底重构为**以多边形地块为权威数据主体、按地块邻接关系运行物理与人文模拟、支持图层自由组合**的现代化地图生成引擎。

### 1.1 纯 .NET 8 领域核心（PlanetGeneration.Core）
- **零外部引擎依赖**：核心库不引用 Godot、不引用任何渲染器或 UI 框架，纯依靠 .NET 8 原生运行时与标准库。
- **高可移植性与可测试性**：核心算法可通过纯控制台程序、单元测试、CI/CD 环境独立运行与验证，摆脱引擎环境启动开销。
- **纯数学几何类型**：定义 `PolyVec2` 与 `WorldExtent`，全面接管世界坐标计算与拓扑变换。

### 1.2 单一权威事实源（WorldSnapshot）
```
                       ┌──────────────────────┐
                       │  GenerationOptions   │ (不可变生成配置)
                       └──────────┬───────────┘
                                  ▼
                       ┌──────────────────────┐
                       │ WorldGenerationService│
                       └──────────┬───────────┘
                                  │
                                  ▼ (发布单向只读快照)
                       ┌──────────────────────┐
                       │    WorldSnapshot     │
                       ├──────────────────────┤
                       │ · CellGeometry (拓扑) │
                       │ · CellFields   (场值) │
                       │ · Settlements  (聚落) │
                       │ · Ecology/Civil(模拟) │
                       │ · WorldStats   (统计) │
                       └──────────┬───────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ▼                        ▼                        ▼
┌──────────────────┐    ┌──────────────────┐    ┌──────────────────┐
│ LayerRenderCoord │    │    MapCanvas     │    │  WorldQuery/AI   │
│ (底图栅格/PNG导出)│    │ (矢量图层/交互高亮)│    │ (悬停/大模型叙事) │
└──────────────────┘    └──────────────────┘    └──────────────────┘
```
- 一次生成完成后，发布完全不可变的 `WorldSnapshot`。
- 渲染、悬停交互、小地图、统计、历史时间轴以及 AI 叙事均只从同一份 `WorldSnapshot` 读取数据，彻底杜绝数据双源分歧。

## 2. 几何网格与空间拓扑系统

### 2.1 圆柱柱面几何（Cylindrical Topology）
- **横向经度无缝环绕（WrapX）**：世界宽度范围为 $[0, Width)$，水平距离与邻接遵循环面最短测地线：
  $$\Delta x = |x_2 - x_1|; \quad \Delta x_{\text{cyl}} = \min(\Delta x, Width - \Delta x)$$
- **纵向纬度硬边界（ClampY）**：南北两极截断在 $[0, Height]$，不进行球面极点缝合，兼顾 2:1 平面全景展示与高效计算。

### 2.2 泊松采样、Voronoi 剖分与松弛
- **抖动方格取点（Jittered Grid）**：根据用户给定的目标地块数 $N_{\text{target}}$ 与地图宽高比，求取最佳行列数 $(C, R)$，并在步长网格内施加确定性伪随机扰动。
- **拓扑邻接与 CSR 压缩稀疏存储**：
  - `CellNeighbors` 与 `CellNeighborStart`：连续整数紧凑数组存储每个地块的邻接地块编号，内存连续，CPU 缓存命中率极高。
  - `CellVertexStart`、`VertexX`、`VertexY`：存储多边形各顶点的逻辑坐标。
  - **拓扑对称性保证**：强制要求若 $j \in Neighbors(i)$，则必定 $i \in Neighbors(j)$。

### 2.3 空间网格索引（SiteIndex）与经度跨缝保护
- 空间桶采用均匀正方形划分。为防止最右列因浮点取整截断出现“薄片桶”（Sliver Bucket），算法采用精确整数列数反推实际桶宽：
  $$Columns = \text{Round}\left(\frac{Width}{Size}\right), \quad BucketWidth = \frac{Width}{Columns}$$
- 查询地块时采用同心环扩张（Ring Search），经度环绕模运算跨越缝隙，并在环距超过当前最近距离候选时提前安全剪枝。

## 3. 分阶段模拟流水线

系统严格遵循前置依赖关系进行单向有序模拟：

```
1. 几何构建 (PolygonGridBuilder)
   └── Voronoi 剖分、Lloyd 松弛、拓扑对称性修补
2. 基础连续物理场生成 (IBaseFieldGenerator)
   └── 板块构造、高程、水力侵蚀、气温、风场、湿度扩散
3. 面积加权采样 (CellFieldSampler)
   └── 连续量加权积分、离散量质心采样至 CellFields
4. 水文拓扑模拟 (PolygonRiverBuilder)
   └── 最陡下降路径建立、局部汇流面积积分、主干与支流生成
5. 综合地貌与群系分类 (PolygonLandformClassifier & CellBiomeClassifier)
   └── 基于地块邻接的地貌判定、惠特克生物群系分类
6. 人文聚落核心选址 (CellSettlementGenerator)
   └── 饮水、平原、资源、港口综合适居度评分与最小距离约束
7. 生态演化与文明疆域 (PolygonEcologySimulator & PolygonCivilizationSimulator)
   └── 闭式图论扩散、势力核心蔓延、政体博弈与冲突热度
8. 权威发布 (WorldSnapshot)
   └── 面积加权真实地理统计、生成完成事件分发
```

## 4. 架构隔离与工程配置

- `PlanetGeneration.Core.csproj`：纯 .NET 8 类库，输出 `PlanetGeneration.Core.dll`。
- `PlanetGeneration.Core.SelfTest.csproj`：纯 .NET 8 自检工程，直接引用 Core 源码进行 7 项严苛断言测试。
- `PlanetGeneration.csproj`（Godot Mono）：通过 `<ProjectReference Include="core\PlanetGeneration.Core.csproj" />` 引用，同时在 csproj 中排除 `core/**` 与 `tests/**` 源码，避免 Godot 引擎扫描器发生类名重复冲突。
